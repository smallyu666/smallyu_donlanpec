# DongLanpec

## 产品复制功能（产品管理）

- 在产品信息表格中，右键已保存的产品行会出现 `复制产品` 菜单。
- 点击后会创建一个新产品：**设备名称（产品名称）** 后缀为 `_副本`，冲突时自动递增为 `_副本2`、`_副本3`；**设备位号** 与原产品相同。
- 新产品会复制原产品的主信息（`产品需求表`）与活动主信息（`产品设计活动表`）。
- 会复制产品设计活动库中所有前缀为 `产品设计活动表_` 的子表记录，复制时自动将 `产品ID` 替换为新产品ID。
- 本地产品目录会同步复制，`pro_id.csv` 会改写为新产品ID；目录缺失时会自动补建并复制模板文件。
- 界面落位：优先占用**第一个尚未绑定产品 ID 的空白行**（仅 1 个产品时一般为第二行），避免出现复制结果跑到第三行；若无空白行再插入新行。
